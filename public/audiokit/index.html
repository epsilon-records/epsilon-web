AudioKit · audio analysis & processing API

Audio analysis and processing, one job at a time.

Send AudioKit a link to a file and the job you want done. It checks the file, does the work and calls your webhook. Originals are never changed, and every result records exactly what produced it.

Capabilities

One request per job

Operations are described by an OpenAPI contract, so the API, the docs and your client stay in step.

01

Analysis

Loudness, tempo and key, with the numbers a mastering or metadata workflow needs.

02

Identification

Audio fingerprints, plus genre and mood tags for organising a catalogue at scale.

03

Processing

Transcodes and previews written to the upload URLs you provide. Originals are untouched.

04

Provenance

Signed webhooks and a result that carries the input hash, AudioKit version and settings.
